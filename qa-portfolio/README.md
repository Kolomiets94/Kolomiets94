# Web Application QA Portfolio

Учебный QA-проект: функциональное тестирование демонстрационного веб-приложения **SauceDemo** (https://www.saucedemo.com/).

> Это самостоятельный демонстрационный проект для портфолио. Примеры дефектов ниже — учебные сценарии, а не подтверждённые ошибки сайта. Автоматизированные тесты включены как код; результаты запуска не заявляются до выполнения CI.

## Что демонстрирует проект
- тест-план и определение области тестирования;
- позитивные и негативные тест-кейсы;
- проверки входа, каталога, корзины и оформления заказа;
- оформление баг-репортов с шагами воспроизведения;
- UI-автоматизацию на Playwright / TypeScript;
- GitHub Actions CI для запуска тестов.

## Локальный запуск
```bash
cd qa-portfolio
npm install
npx playwright install chromium
npm test
```

Просмотр HTML-отчёта:
```bash
npm run report
```

## Подход
Приоритет: критические пользовательские пути (авторизация → выбор товара → корзина → оформление), затем негативные сценарии и интерфейсные проверки. Тестовые данные взяты из публичного демонстрационного приложения.
