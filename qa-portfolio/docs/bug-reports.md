# Примеры оформления баг-репортов

> **Важно:** это учебные гипотетические дефекты, не обнаруженные и не подтверждённые на SauceDemo. Используются только для демонстрации навыка оформления.

## DEMO-BUG-01 — Неверный счётчик корзины
- **Тип:** пример, не реальный дефект
- **Severity:** Major
- **Priority:** High
- **Предусловие:** пользователь вошёл, корзина пуста
- **Шаги:** 1. Добавить один товар. 2. Посмотреть на значок корзины.
- **Ожидаемо:** счётчик показывает 1.
- **Гипотетический фактический результат:** счётчик показывает 0.
- **Вложения:** отсутствуют (демонстрационный кейс).
- **Статус:** Example / Not reproduced.

## DEMO-BUG-02 — Форма checkout принимает пустое имя
- **Тип:** пример, не реальный дефект
- **Severity:** Major
- **Priority:** High
- **Предусловие:** в корзине есть товар, открыт checkout
- **Шаги:** 1. Оставить First Name пустым. 2. Заполнить остальные поля. 3. Нажать Continue.
- **Ожидаемо:** валидация блокирует переход, показана ошибка.
- **Гипотетический фактический результат:** форма переходит к подтверждению.
- **Вложения:** отсутствуют (демонстрационный кейс).
- **Статус:** Example / Not reproduced.
