# Тест-план: SauceDemo

**Цель:** проверить основные пользовательские сценарии демонстрационного интернет-магазина.

**Объект:** https://www.saucedemo.com/  
**Виды тестирования:** smoke, функциональное, негативное, регрессионное (выборочно), UI.  
**Среда:** Chromium, desktop; расширение на мобильные браузеры — отдельный этап.

## Область проверки
1. Авторизация: корректные и некорректные данные, сообщения об ошибках.
2. Каталог: наличие товаров, названия, цены и кнопки добавления.
3. Корзина: добавление, удаление, счётчик, сохранение выбранного.
4. Checkout: обязательные поля, переходы, подтверждение заказа.

## Вне области
Оплата реальными деньгами, backend-нагрузка, безопасность сервера, интеграции третьих сторон.

## Критерии начала
Сайт доступен, тестовая учётная запись работает, браузер установлен.

## Критерии завершения
Пройдены критические сценарии, результаты задокументированы, обнаруженные реальные дефекты оформлены с доказательствами.

## Риски
Изменение UI/селекторов, нестабильность внешнего демонстрационного сайта, ограничения тестовой среды.

## Артефакты
Тест-кейсы, баг-репорты, Playwright HTML report, скриншоты и trace при падении тестов.
