# Career MCP

Локальный MCP-сервер для поиска и хранения публичных вакансий, аудита резюме и подготовки обращений к рекрутерам. Сборщики работают read-only: не входят в аккаунты, не обходят CAPTCHA и не отправляют отклики или сообщения.

## Возможности

### Поиск вакансий и локальная база

- `career_search_hh_vacancies` — формирует ссылку на веб-поиск HH.ru; автоматический неавторизованный запрос к API HH не используется.
- `career_search_habr_vacancies` — читает публичные категории Хабр Карьеры (React, Frontend, HTML, JavaScript), извлекает ссылки и пытается получить описание карточек.
- `career_search_telegram_vacancies` — читает публичные web-preview `t.me/s/<channel>`; каналы задаются параметром, список по умолчанию является набором кандидатов, а не гарантированно проверенным каталогом.
- `career_search_geekjob_vacancies` — читает публичный каталог GeekJob и пытается обогатить первые совпавшие карточки.
- `career_search_getmatch_vacancies` — использует публичный JSON endpoint Getmatch; доступность и структура API могут меняться.
- `career_import_vacancies` — импортирует нормализованные записи в локальную JSON-базу.
- `career_list_vacancies` — фильтрует сохранённые вакансии по словам, региону, удалёнке, зарплате и статусу.

Карточки из сборщиков сохраняются в `.career-data/vacancies.json`. Повторный импорт обновляет существующую запись по каноническому URL. Неизвестные поля не заполняются догадками. Зарплатный порог и зарплатный скоринг сравнивают только суммы в RUB; суммы в других валютах не конвертируются.

### Резюме и контакты

- `hh_prepare_resume_review` — подготавливает текст экспортированного резюме для анализа ИИ-клиентом.
- `hh_compare_resume_versions` — подготавливает сравнение двух версий резюме.
- `career_recruiter_search_brief` — формирует задание для поиска публичных профессиональных контактов рекрутеров. Сам по себе инструмент веб-поиск не выполняет.
- `career_prepare_recruiter_message` — подготавливает черновик обращения, но не отправляет его.

Личные контакты и закрытые данные не собираются. Любая отправка или изменение профиля требует отдельного действия пользователя.

## Установка и локальная проверка

Требуется Node.js 20+.

```bash
npm install
npm run check:local
```

Команда `check:local` выполняет TypeScript typecheck, smoke-тест локального хранилища во временной папке и сетевые smoke-проверки публичных источников. Сетевые проверки могут завершиться ошибкой из-за ограничений сайтов, антибот-защиты или изменений разметки.

Отдельные команды:

```bash
npm run typecheck
npm run smoke:store
npm run smoke:sources
```

## Подключение MCP-клиента

Пример конфигурации для локального MCP-клиента:

```json
{
  "mcpServers": {
    "career-mcp": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/hh-resume-mcp/src/index.ts"],
      "cwd": "/ABSOLUTE/PATH/hh-resume-mcp"
    }
  }
}
```

Замените `/ABSOLUTE/PATH` на фактический путь к папке проекта. Локальная база сохраняется относительно рабочей папки процесса MCP.

## HH.ru

Инструмент не входит в аккаунт HH, не использует OAuth-токены, не обходит CAPTCHA и не изменяет резюме. `career_search_hh_vacancies` только формирует ссылку на веб-поиск. Для аудита экспортируйте текст резюме и передайте его в `hh_prepare_resume_review`.

## Фильтрация

`career_list_vacancies` по умолчанию исключает роли, в названии которых указаны QA/тестирование, поддержка, операторские обязанности или продажи. Это фильтр по названию, а не по полному описанию.

## Ограничения и безопасность

- Сборщики читают только публичные HTTPS-страницы и API.
- Не выполняются вход в аккаунты, обход CAPTCHA/paywall или доступ к закрытым каналам.
- Не отправляются отклики, письма и сообщения.
- Результаты являются кандидатами на вакансии: актуальность, грейд и условия нужно сверять на исходной странице.
- Локальная база — JSON-файл без синхронизации между устройствами.
- Ранее в зависимостях отмечался high-severity advisory. Не запускайте `npm audit fix --force` без анализа дерева зависимостей и совместимости.
- Автоматический CI workflow в репозитории не используется; проверки запускаются локально командой `npm run check:local`.
