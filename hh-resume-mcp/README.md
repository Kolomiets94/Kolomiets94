# HH Resume MCP

Локальный MCP-сервер для безопасного чтения данных собственного аккаунта HeadHunter и анализа резюме с помощью MCP-клиента.

**Текущий режим — read-only.** Сервер не редактирует, не публикует, не удаляет резюме и не отправляет отклики. Методы записи будут добавляться только после проверки актуальной официальной схемы API и отдельного подтверждения владельца.

## Возможности

- `hh_get_profile` — профиль авторизованного пользователя (`GET /me`)
- `hh_list_my_resumes` — список собственных резюме (`GET /resumes/mine`)
- `hh_get_resume` — подробные данные собственного резюме (`GET /resumes/{resume_id}`)

## Требования

- Node.js 20+
- Зарегистрированное OAuth-приложение HH с разрешённым redirect URI `http://localhost:8765/callback`
- MCP-клиент, поддерживающий stdio

## Установка

1. Скопируй `.env.example` в `.env`.
2. Внеси `HH_CLIENT_ID` и `HH_CLIENT_SECRET` из кабинета разработчика HH. Не отправляй эти значения в чат и не коммить их в Git.
3. Убедись, что в настройках приложения HH указан redirect URI в точности: `http://localhost:8765/callback`.
4. Выполни:

```bash
npm install
npm run auth
```

5. Открой напечатанную ссылку, войди в HH и подтверди доступ. После callback токены сохранятся в локальный файл `.tokens.json` с ограниченными правами доступа.
6. Запусти MCP:

```bash
npm run mcp
```

## Конфигурация MCP-клиента

Пример для клиента с поддержкой stdio; замени абсолютный путь на свой:

```json
{
  "mcpServers": {
    "hh-resume": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/hh-resume-mcp/src/index.ts"],
      "cwd": "/ABSOLUTE/PATH/hh-resume-mcp"
    }
  }
}
```

Перед запуском MCP-процесса должны быть доступны переменные из `.env`. Если MCP-клиент не загружает `.env` автоматически, используй локальный launcher или передай переменные окружения из менеджера секретов клиента.

## Безопасность

- Никогда не добавляй `.env` или `.tokens.json` в Git.
- Не передавай пароль HH, client secret, access token или refresh token в чат.
- OAuth авторизация открывается на официальном домене `hh.ru`; пароль вводится только на сайте HH.
- Сервер слушает stdio и не открывает публичный HTTP API.
- Токены сохраняются только на локальном компьютере.
- Если токен скомпрометирован, отзови доступ приложения в настройках HH.

## Примечания

HH требует корректный `User-Agent` для запросов API. Задай описательное значение в `HH_USER_AGENT`, если HH требует указать контакт разработчика.
