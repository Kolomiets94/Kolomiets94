# Career MCP

Локальный MCP-сервер для поиска и хранения публичных вакансий, аудита резюме и подготовки обращений к рекрутерам. Все сборщики работают read-only: не входят в аккаунты, не обходят CAPTCHA и не отправляют отклики или сообщения.

## Возможности

### Поиск вакансий и локальная база

- `career_search_hh_vacancies` — формирует ссылку на веб-поиск HH.ru. Автоматический неавторизованный запрос к API HH не используется.
- `career_search_habr_vacancies` — читает публичные категории Хабр Карьеры (React, Frontend, HTML, JavaScript), извлекает ссылки вакансий и пытается получить описание карточки.
- `career_search_telegram_vacancies` — читает публичные web-preview `t.me/s/<channel>`, отбирает сообщения по ключевым словам и признакам вакансии.
- `career_search_geekjob_vacancies` — читает публичный каталог GeekJob, отбирает ссылки `/vacancy/<id>` и получает подробности первых восьми карточек.
- `career_search_getmatch_vacancies` — использует публичный JSON API `GET https://getmatch.ru/api/offers?offset=&limit=`, обходит до пяти страниц по 100 предложений и обогащает первые восемь совпадений через `/api/offers/<id>`.
- `career_import_vacancies` — импортирует нормализованные записи в локальную JSON-базу.
- `career_list_vacancies` — фильтрует сохранённые вакансии по словам, региону, удалёнке, зарплате и статусу.

Распознанные карточки из четырёх публичных сборщиков автоматически сохраняются в `.career-data/vacancies.json`. Повторный импорт обновляет существующую запись по каноническому URL. Поля, которые источник не предоставил, остаются пустыми — парсер не должен их угадывать.

### Резюме и контакты

- `hh_prepare_resume_review` — анализирует текст резюме, экспортированный пользователем.
- `hh_compare_resume_versions` — сравнивает две версии резюме.
- `career_recruiter_search_brief` — формирует задание на поиск публичных профессиональных контактов рекрутеров.
- `career_prepare_recruiter_message` — подготавливает персональный черновик обращения, но не отправляет его.

Личные контакты, закрытые данные, cookies и доступ к аккаунтам не собираются. Любая отправка или изменение профиля требует отдельного действия пользователя.

## Установка

Требуется Node.js 20+.

```bash
npm install
npm run typecheck
npm run smoke:sources
```

## Подключение MCP-клиента

Пример конфигурации для локального MCP-клиента:

```json
{
  "mcpServers": {
    "career-mcp": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/hh-resume-mcp/src/index.ts"],
      "cwd": "/ABSOLUTE/PATH/hh-resume-mcp"
    }
  }
}
```

Замените `/ABSOLUTE/PATH` на фактический путь к папке проекта. Данные локальной базы сохраняются относительно рабочей папки процесса MCP.

## HH.ru

Поддержка API для соискателей ограничена; проект не использует обход CAPTCHA, не запрашивает OAuth-токены и не изменяет резюме в аккаунте. `career_search_hh_vacancies` только формирует ссылку на веб-поиск. Для аудита резюме экспортируйте его текст и передайте в `hh_prepare_resume_review`.

## Фильтрация

`career_list_vacancies` по умолчанию исключает роли, в названии которых указаны QA/тестирование, поддержка, операторские обязанности или продажи (`exclude_irrelevant: true`). Это фильтр по названию, чтобы не исключать Frontend-вакансии только из-за упоминания QA или поддержки в описании.

## Проверки

GitHub Actions выполняет:

1. `npm install`
2. `npm run typecheck`
3. `npm run smoke:sources`

Последний успешный прогон: [GitHub Actions](https://github.com/Kolomiets94/Kolomiets94/actions/runs/41439012418).

Smoke-проверка обращается к публичным страницам/эндпоинтам и проверяет HTTP-ответ и наличие ссылок или записей. В успешном прогоне обнаружено:
- Хабр Карьера — 15 ссылок-кандидатов;
- GeekJob — 6 ссылок-кандидатов;
- Getmatch — 22 предложения в публичном API;
- Telegram `@forfrontend` — 20 публичных сообщений-кандидатов.

Это подтверждает доступность источников и базовые селекторы на момент проверки, но не является полным end-to-end тестом MCP-инструментов или локальной записи в базу. Разметка сайтов и доступность публичных эндпоинтов могут меняться. Перед практическим использованием проверьте найденные вакансии на исходной странице.

## Ограничения и безопасность

- Сборщики читают только публичные HTTPS-страницы и API.
- Не выполняются вход в аккаунты, обход CAPTCHA, обход paywall или доступ к закрытым каналам.
- Не отправляются отклики, письма, сообщения и запросы на добавление в контакты.
- Вакансии могут быть устаревшими или неподходящими по грейду; проверяйте условия на странице работодателя.
- Локальная база — JSON-файл, без синхронизации между устройствами.
- В CI при установке зависимостей был обнаружен один high-severity advisory. До выяснения конкретной зависимости не выполняйте `npm audit fix --force`.
