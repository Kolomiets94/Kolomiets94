# HH Resume MCP

Локальный MCP-инструмент для подготовки и проверки собственного резюме HeadHunter.

## Важное ограничение HH API

В кабинете разработчика HH указано, что поддержка API для соискателей прекращена 15 декабря 2025 года. Поэтому проект не обходит это ограничение, не регистрируется как приложение работодателя и не запрашивает OAuth-токены.

Официальная документация API по-прежнему описывает отдельные методы соискателя, но наличие таких описаний не гарантирует одобрение новых приложений или доступ к чтению и изменению собственного резюме. Старые вызовы GET /resumes/mine и GET /resumes/{resume_id} удалены из проекта: их доступность для нового приложения соискателя не подтверждена.

## Возможности

- hh_prepare_resume_review — передать текст резюме, экспортированный из HH, на аудит под целевую роль.
- hh_compare_resume_versions — сравнить старую и новую версии, найти улучшения, регрессии и неподтверждённые утверждения.

Инструмент не входит в аккаунт HH, не редактирует профиль и не отправляет отклики. После аудита пользователь вручную вносит согласованные изменения на hh.ru.

## Установка

Требуется Node.js 20+.

```bash
npm install
npm run typecheck
```

## Playwright для интерфейса HH

Я нашёл существующую реализацию Playwright в [ai-job-search-personal](https://github.com/Kolomiets94/ai-job-search-personal): там используется Python-пакет `playwright` для обхода публичных страниц вакансий. Это обычный браузерный скрипт, не MCP-сервер, и он не умеет работать с авторизованным профилем HH.

Для этого проекта подключён официальный [Microsoft Playwright MCP](https://github.com/microsoft/playwright-mcp). Он запускается отдельно и предоставляет ИИ-клиенту инструменты управления браузером.

Добавь в конфигурацию своего MCP-клиента:

```json
{
  "mcpServers": {
    "hh-resume": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/hh-resume-mcp/src/index.ts"],
      "cwd": "/ABSOLUTE/PATH/hh-resume-mcp"
    },
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Либо из папки проекта запусти браузерный MCP отдельно:

```bash
npm run playwright
```

Playwright MCP по умолчанию открывает видимый браузер и использует постоянный профиль, в котором сохраняется состояние входа между запусками. При первом запуске открой hh.ru и войди самостоятельно. Не передавай пароль, коды подтверждения или cookies в чат.

Перед сохранением любых изменений резюме сначала проверь подготовленный текст и подтверди действие. Playwright автоматизирует обычный пользовательский интерфейс; доступность конкретных действий зависит от интерфейса и ограничений аккаунта HH.

## Использование анализатора резюме

1. Открой своё резюме на hh.ru.
2. Сохрани или экспортируй его в PDF.
3. Скопируй текст из PDF.
4. Вызови hh_prepare_resume_review, передав текст и целевую должность.
5. Проверь предложенные формулировки и внеси подходящие изменения на HH через браузер.

Не передавай лишние персональные данные, если они не нужны для анализа. При желании удали телефон, email и адрес перед отправкой текста.
