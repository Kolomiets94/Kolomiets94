# HH Resume MCP

Локальный MCP-инструмент для read-only поиска публичных вакансий HH.ru, подготовки и проверки резюме и работы с карьерными контактами.

## Важное ограничение HH API

В кабинете разработчика HH указано, что поддержка API для соискателей прекращена 15 декабря 2025 года. Поэтому проект не обходит это ограничение, не регистрируется как приложение работодателя и не запрашивает OAuth-токены.

Официальная документация API по-прежнему описывает отдельные методы соискателя, но наличие таких описаний не гарантирует одобрение новых приложений или доступ к чтению и изменению собственного резюме. Старые вызовы GET /resumes/mine и GET /resumes/{resume_id} удалены из проекта: их доступность для нового приложения соискателя не подтверждена.

## Возможности

- `career_search_hh_vacancies` — формирование ссылки на веб-поиск HH.ru. Автоматический неавторизованный API-поиск не используется из-за CAPTCHA/ограничений доступа.
- `career_import_vacancies` — нормализация и импорт вакансий из разных источников в локальную JSON-базу с дедупликацией.
- `career_list_vacancies` — фильтрация сохранённых вакансий по словам, региону, удалёнке, зарплате и статусу.

- hh_prepare_resume_review — передать текст резюме, экспортированный из HH, на аудит под целевую роль.
- hh_compare_resume_versions — сравнить старую и новую версии, найти улучшения, регрессии и неподтверждённые утверждения.

Инструмент не входит в аккаунт HH, не редактирует профиль и не отправляет отклики. После аудита пользователь вручную вносит согласованные изменения на hh.ru.\n\nДополнительно доступны инструменты подготовки поиска рекрутеров и персональных обращений: `career_recruiter_search_brief` и `career_prepare_recruiter_message`. Они формируют подробное задание для ИИ-клиента и черновик сообщения. Они сами не выполняют веб-поиск, не хранят историю контактов и ничего не отправляют. Для реального поиска ИИ-клиент должен использовать подключённый браузер/поисковый инструмент и соблюдать правила площадок.

## Установка

Требуется Node.js 20+.

```bash
npm install
npm run typecheck
```

## Получение вакансий и Playwright

Автоматический поиск HH через неавторизованный `api.hh.ru/vacancies` отключён. В текущей документации HH указано, что без OAuth после первого запроса предлагается CAPTCHA; в 2026 году также появились сообщения о 403 для публичной выдачи. Инструмент `career_search_hh_vacancies` поэтому только формирует ссылку на веб-поиск HH. Никакого обхода CAPTCHA или авторизации нет. Ссылки и найденные вручную объявления можно передать в `career_import_vacancies`.

## Playwright для интерфейса HH

Я нашёл существующую реализацию Playwright в [ai-job-search-personal](https://github.com/Kolomiets94/ai-job-search-personal): там используется Python-пакет `playwright` для обхода публичных страниц вакансий. Это обычный браузерный скрипт, не MCP-сервер, и он не умеет работать с авторизованным профилем HH.

Для этого проекта подключён официальный [Microsoft Playwright MCP](https://github.com/microsoft/playwright-mcp). Он запускается отдельно и предоставляет ИИ-клиенту инструменты управления браузером.

Добавь в конфигурацию своего MCP-клиента:

```json
{
  "mcpServers": {
    "hh-resume": {
      "command": "npx",
      "args": ["tsx", "/ABSOLUTE/PATH/hh-resume-mcp/src/index.ts"],
      "cwd": "/ABSOLUTE/PATH/hh-resume-mcp"
    },
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Либо из папки проекта запусти браузерный MCP отдельно:

```bash
npm run playwright
```

Поведение профиля браузера зависит от версии и параметров Playwright MCP. Не рассчитывай на сохранение авторизации без отдельной проверки; при необходимости войди вручную в открытом браузере. Не передавай пароль, коды подтверждения или cookies в чат.

Перед сохранением любых изменений резюме сначала проверь подготовленный текст и подтверди действие. Playwright автоматизирует обычный пользовательский интерфейс; доступность конкретных действий зависит от интерфейса и ограничений аккаунта HH.

## Использование анализатора резюме

1. Открой своё резюме на hh.ru.
2. Сохрани или экспортируй его в PDF.
3. Скопируй текст из PDF.
4. Вызови hh_prepare_resume_review, передав текст и целевую должность.
5. Проверь предложенные формулировки и внеси подходящие изменения на HH через браузер.

Не передавай лишние персональные данные, если они не нужны для анализа. При желании удали телефон, email и адрес перед отправкой текста.

## Статус реализации

Поиск публичных вакансий HH добавлен в код, но ещё не запускался в локальной среде пользователя и не проходил `npm run typecheck` в этом репозитории. Перед использованием выполни проверку типов и тестовый вызов `career_search_hh_vacancies`. Публичные страницы других площадок (Хабр Карьера, GeekJob, Getmatch, Telegram и сайты компаний) пока не подключены как отдельные рабочие адаптеры.

## Локальная база вакансий

Инструменты `career_import_vacancies` и `career_list_vacancies` используют файл `.career-data/vacancies.json` в рабочей папке процесса MCP. Вакансии нормализуются к общей схеме, URL очищаются от типовых рекламных параметров, повторный импорт обновляет существующую запись вместо создания дубля. Статус записи: `new`, `seen`, `applied`, `rejected` или `archived`.

Важно: импортёр — это слой хранения и дедупликации, а не самостоятельный парсер всех перечисленных сайтов. Чтобы данные попали в базу, их должен передать MCP-клиент после получения из публичной страницы, поиска или другого разрешённого источника. Автоматические адаптеры Хабр Карьеры, GeekJob, Getmatch и Telegram ещё не реализованы. Не обходи авторизацию, CAPTCHA, ограничения доступа или правила сайтов.

## Публичные сборщики

- `career_search_habr_vacancies` читает публичную выдачу Хабр Карьеры по React, Frontend, HTML/CSS или JavaScript и извлекает ссылки-кандидаты на вакансии.
- `career_search_telegram_vacancies` читает публичные web-preview `t.me/s/<channel>` для списка каналов и фильтрует последние сообщения по ключевым словам. По умолчанию: `forfrontend`, `frontend_rabota`, `senior_frontender`, `job_react`.

Это первичные HTML-сборщики: разметка сайтов может меняться, часть карточек может не распознаться, а публикации могут содержать устаревшие вакансии. Перед импортом проверьте исходную публикацию. Запросы выполняются последовательно и только к публичным страницам; нет авторизации, обхода CAPTCHA или доступа к закрытым каналам.

На момент проверки каталог Хабр Карьеры содержит отдельные категории React-разработчиков и Frontend-вакансий: https://career.habr.com/catalog/vacancies. Публичные Telegram-ленты каналов можно просматривать по адресу `https://t.me/s/<channel>`.
